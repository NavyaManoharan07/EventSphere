Design a complete modern AI-powered event discovery, networking, and ticketing platform called “EventSphere AI” using a premium hybrid glassmorphism UI style with clean layouts, futuristic gradients, floating cards, and smooth microinteractions.

The platform combines career-focused events and entertainment events into one intelligent ecosystem.

The UI should feel:

* Premium
* Modern
* Intelligent
* Community-driven
* Startup-quality
* Interactive
* Minimal yet colorful

Avoid overly dark cyberpunk styles and avoid fully plain white interfaces.
